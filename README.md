# AI Handbook

Learning how AI actually works, from first principles.

## What's here

- **Core Concepts** - ML, deep learning, LLMs and how they connect
- **How Things Work** - The anatomy of real projects (RAG systems, fine-tuning, retrieval, etc.)
- **Implementation Paths** - Where to start if you want to build X
- **Glossary** - Quick reference for terminology

## Why this exists

For people (including me) who use AI tools but want to understand what's actually happening underneath. This is a learning-in-public notebook, not a polished tutorial.

## How to use it

Start with the concept map, or jump to whatever question you have. It's organized by idea, not by tool or framework.
